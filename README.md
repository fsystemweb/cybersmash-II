# CYBER SMASH

A comedic 3D browser game: a 2.5D homage to the "wreck the car" bonus stage of early-90s
arcade fighters. A sweaty harbor salesman can't sell his ugly angular electric pickup — the
**CYBERCHUNK** — so he pays anyone who can smash it with their bare hands in under 40 seconds.

Built with [three.js](https://threejs.org/) in a single `index.html`. No build step, no assets:
every model, texture, letter and sound is generated at runtime.

> Work in progress — see the pull requests for the build-up of the game.
